# Full-AES results

The full-AES distinguisher runs (`distribution/`) and key-recovery runs (`keyrecovery/`) are being
produced with `scripts/run_full_aes.sh` and will be added when complete.
`lambda_structure/` contains the exact lambda_S of random structures (`Codes/aes/lambda_structure.py`),
and `previous_100_trials/` the results of the previous version of the paper.
